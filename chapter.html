Introduction

Meaning and importance of the topic.

1.1

Introduction to Sets

A set is a well-defined collection of distinct objects. The objects are called its elements (or members).

Sets are named with capital letters. We write x ∈ A if x belongs to A, and x ∉ A if it does not.

Key idea

"Well-defined" means we can say clearly whether an object belongs or not. "The vowels of the English alphabet" is a set. "Tall students in a class" is not, because "tall" is not clear.

Standard sets: N natural numbers, Z integers, Q rational numbers, R real numbers.

Why sets matter

  • Sets are the language of mathematics. Functions, relations, probability and number systems are all described using sets.
  • Class 12 link: Relations and Functions (domain, range, Cartesian product) and Probability (events are subsets of the sample space) use set notation and Venn diagrams every day.
  • JEE link: set ideas appear directly in counting questions and are a tool inside Algebra, Probability and Functions problems.
  • Skills you build: reading symbols, writing short logical proofs (x ∈ A ⇒ x ∈ B) and counting without missing or repeating cases.

Basic Concepts

Definitions and fundamental properties.

1.2

Representation of Sets

There are two ways to write a set.

  • Roster (tabular) form: list the elements inside braces, for example {a, e, i, o, u}.
  • Set-builder form: state the property, for example {x : x is a vowel of the English alphabet}.
Remember

Order does not matter, and repeating an element changes nothing: {1, 2, 2, 3} = {3, 1, 2}.

1.3

Roster and Set-Builder Forms

To convert from set-builder to roster form, find every value that satisfies the property. To go back, find a rule that describes all the elements.

Example 1. Write A = {x : x ∈ N, x² < 20} in roster form.

Show solution

Check x = 1, 2, 3, 4: squares 1, 4, 9, 16 are less than 20. For x = 5 the square is 25, which is not. So A = {1, 2, 3, 4}.

Example 2. Write {2, 4, 6, 8, 10} in set-builder form.

Show solution

These are the first five even natural numbers: {x : x = 2n, n ∈ N, n ≤ 5}.

1.4

Types of Sets

  • Empty set ∅ or { }: has no elements.
  • Singleton set: has exactly one element.
  • Finite set: counting its elements comes to an end. Infinite set: it does not (like N).
  • Equal sets: have exactly the same elements.
  • Equivalent sets: have the same number of elements, n(A) = n(B).
Key idea

Equal sets are always equivalent, but equivalent sets need not be equal. {1, 2} and {a, b} are equivalent but not equal.

Common mistake

{0} is not empty (it has one element, 0). {∅} is not empty either (it has one element, ∅).

1.5

Subsets and Proper Subsets

A ⊆ B (A is a subset of B) if every element of A is also in B. A ⊂ B (proper subset) if A ⊆ B and A ≠ B.

  • ∅ is a subset of every set, and every set is a subset of itself.
  • If A ⊆ B and B ⊆ A, then A = B.
A set with n elements has 2ⁿ subsets, 2ⁿ − 1 proper subsets and 2ⁿ − 2 non-empty proper subsets.

Example. List all subsets of {a, b, c}.

Show solution

∅, {a}, {b}, {c}, {a, b}, {a, c}, {b, c}, {a, b, c}. That is 8 = 2³ subsets.

1.6

Power Set

The power set P(A) is the set of all subsets of A. For A = {1, 2}: P(A) = {∅, {1}, {2}, {1, 2}}.

n(P(A)) = 2ⁿ, where n = n(A)
JEE tip

If n(P(A)) = 64, then 2ⁿ = 64, so n(A) = 6.

1.7

Universal Set

The universal set U contains all the objects under discussion. Every set in that discussion is a subset of U.

U depends on the problem. For A = {1, 2} and B = {2, 3}, we can take U = {1, 2, 3} or U = N.

3

Theory & Theorems

Complete explanation of operations, laws and proofs.

1.8

Union and Intersection

Union: A ∪ B = {x : x ∈ A or x ∈ B}. Intersection: A ∩ B = {x : x ∈ A and x ∈ B}. If A ∩ B = ∅, the sets are disjoint.

A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

Both operations are commutative (A ∪ B = B ∪ A) and associative.

Example. A = {1, 2, 3, 4}, B = {3, 4, 5, 6}. Find A ∪ B and A ∩ B.

Show solution

A ∪ B = {1, 2, 3, 4, 5, 6} and A ∩ B = {3, 4}.

1.9

Difference of Sets

A − B = {x : x ∈ A and x ∉ B}. These are the elements of A that are not in B.

  • In general A − B ≠ B − A.
  • A − B = A ∩ B′.

Example. A = {1, 2, 3, 4, 5}, B = {4, 5, 6, 7}. Find A − B and B − A.

Show solution

A − B = {1, 2, 3} and B − A = {6, 7}.

1.10

Complement of a Set

A′ = U − A = {x : x ∈ U and x ∉ A}.

A ∪ A′ = U, A ∩ A′ = ∅, (A′)′ = A, ∅′ = U, U′ = ∅

Example. U = {1, 2, …, 10}, A = {2, 4, 6, 8, 10}. Find A′.

Show solution

A′ = {1, 3, 5, 7, 9}.

1.11

Symmetric Difference

A Δ B contains the elements that are in exactly one of the two sets.

A Δ B = (A − B) ∪ (B − A) = (A ∪ B) − (A ∩ B)

Example. A = {1, 2, 3}, B = {3, 4}. Find A Δ B.

Show solution

A − B = {1, 2} and B − A = {4}. So A Δ B = {1, 2, 4}.

1.12

Venn Diagrams

A Venn diagram uses a rectangle for U and circles for sets. Shaded regions show the result of an operation. Click an operation to see it.

1.13

De Morgan's Laws

(A ∪ B)′ = A′ ∩ B′
(A ∩ B)′ = A′ ∪ B′
Memory trick

Break the bar, change the sign: the complement splits across the brackets and ∪ becomes ∩ (and ∩ becomes ∪).

Example. U = {1, …, 6}, A = {1, 2, 3}, B = {3, 4}. Verify (A ∪ B)′ = A′ ∩ B′.

Show solution

A ∪ B = {1, 2, 3, 4}, so (A ∪ B)′ = {5, 6}. Also A′ = {4, 5, 6} and B′ = {1, 2, 5, 6}, so A′ ∩ B′ = {5, 6}. Both sides are equal.

1.14

Number of Elements in Sets

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
n(A − B) = n(A) − n(A ∩ B)
n(A ∪ B ∪ C) = n(A) + n(B) + n(C) − n(A ∩ B) − n(B ∩ C) − n(A ∩ C) + n(A ∩ B ∩ C)

Example. In a class of 60, 35 like cricket, 28 like football and 10 like both. How many like neither? How many like only cricket?

Show solution

n(C ∪ F) = 35 + 28 − 10 = 53, so neither = 60 − 53 = 7. Only cricket = 35 − 10 = 25.

Theorems and proofs

Theorem 1 (number of subsets). A set with n elements has 2ⁿ subsets.
Proof

Each of the n elements has two choices: it is in the subset or it is not. By the multiplication principle the number of subsets is 2 × 2 × … × 2 (n times) = 2ⁿ.

Theorem 2 (De Morgan's laws). (A ∪ B)′ = A′ ∩ B′ and (A ∩ B)′ = A′ ∪ B′.
Proof

x ∈ (A ∪ B)′ ⇔ x ∉ A ∪ B ⇔ x ∉ A and x ∉ B ⇔ x ∈ A′ and x ∈ B′ ⇔ x ∈ A′ ∩ B′. Hence (A ∪ B)′ = A′ ∩ B′. The second law is proved in the same way, with "and" and "or" exchanged.

Theorem 3 (difference as an intersection). A − B = A ∩ B′.
Proof

x ∈ A − B ⇔ x ∈ A and x ∉ B ⇔ x ∈ A and x ∈ B′ ⇔ x ∈ A ∩ B′.

Theorem 4 (distributive law). A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C).
Proof

x ∈ A ∩ (B ∪ C) ⇔ x ∈ A and (x ∈ B or x ∈ C) ⇔ (x ∈ A and x ∈ B) or (x ∈ A and x ∈ C) ⇔ x ∈ (A ∩ B) ∪ (A ∩ C).

Theorem 5 (counting two sets). n(A ∪ B) = n(A) + n(B) − n(A ∩ B).
Proof

A ∪ B splits into three disjoint parts: A − B, A ∩ B and B − A. Also n(A) = n(A − B) + n(A ∩ B) and n(B) = n(B − A) + n(A ∩ B). Adding, n(A) + n(B) = n(A − B) + n(B − A) + 2n(A ∩ B), while n(A ∪ B) = n(A − B) + n(B − A) + n(A ∩ B). Subtracting gives the formula.

Solved Examples

Basic, intermediate and advanced.

1.15

Applications of Sets in JEE

  • Counting subsets: fix the elements that must be present, and choose freely from the rest.
  • Word problems with 2 or 3 groups: draw a Venn diagram and use the formulas of 1.14.
  • Minimum and maximum of n(A ∪ B) or n(A ∩ B): think of the extreme cases (one inside the other, or disjoint).

Solved examples

BasicExample 1. Write A = {x : x is a prime number less than 12} in roster form.

Show solution

The primes below 12 are 2, 3, 5, 7, 11. So A = {2, 3, 5, 7, 11}.

BasicExample 2. A = {1, 2, 3, 4}, B = {3, 4, 5, 6}. Find A ∪ B, A ∩ B and A − B.

Show solution

A ∪ B = {1, 2, 3, 4, 5, 6}, A ∩ B = {3, 4}, A − B = {1, 2}.

BasicExample 3. How many subsets and proper subsets does {a, b, c, d} have?

Show solution

n = 4, so subsets = 2⁴ = 16 and proper subsets = 16 − 1 = 15.

IntermediateExample 4. Of 100 students, 60 study Maths, 50 study Physics and 20 study both. How many study neither? How many study only Maths?

Show solution

n(M ∪ P) = 60 + 50 − 20 = 90, so neither = 100 − 90 = 10. Only Maths = 60 − 20 = 40.

IntermediateExample 5. Verify A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) for A = {1, 2}, B = {2, 3}, C = {3, 4}.

Show solution

B ∪ C = {2, 3, 4}, so A ∩ (B ∪ C) = {2}. Also A ∩ B = {2} and A ∩ C = ∅, so (A ∩ B) ∪ (A ∩ C) = {2}. Both sides are equal.

IntermediateExample 6. A = {x : x² − 5x + 6 = 0} and B = {2, 4, 6}. Find A Δ B.

Show solution

x² − 5x + 6 = 0 gives x = 2, 3, so A = {2, 3}. A − B = {3} and B − A = {4, 6}. So A Δ B = {3, 4, 6}.

JEE typeExample 7. n(A) = 3 and n(B) = 6. Find the minimum and maximum of n(A ∪ B).

Show solution

Minimum: A ⊆ B, so n(A ∪ B) = 6. Maximum: A and B disjoint, so n(A ∪ B) = 3 + 6 = 9.

JEE typeExample 8. How many subsets of {1, 2, 3, 4, 5} contain at least one of 1 and 2?

Show solution

Total subsets = 2⁵ = 32. Subsets with neither 1 nor 2 are the subsets of {3, 4, 5}, which number 2³ = 8. So the answer is 32 − 8 = 24.

JEE typeExample 9. n(A) = 30, n(B) = 25, n(C) = 20, n(A ∩ B) = 10, n(B ∩ C) = 8, n(A ∩ C) = 6 and n(A ∩ B ∩ C) = 4. Find n(A ∪ B ∪ C).

Show solution

n(A ∪ B ∪ C) = 30 + 25 + 20 − 10 − 8 − 6 + 4 = 55.

JEE typeExample 10. If n(A) = 2, find n(P(P(A))).

Show solution

n(P(A)) = 2² = 4. Then n(P(P(A))) = 2⁴ = 16.

NCERT-style questions

These are written in the style of NCERT exercises (they are not copied from the book). Try each one before opening the answer, then compare with the official NCERT exercises for this chapter.

Q1. Write {x : x is a positive integer and x² < 40} in roster form.

Show answer

x = 1, 2, …, 6 (since 6² = 36 and 7² = 49). The set is {1, 2, 3, 4, 5, 6}.

Q2. Write {1, 1/2, 1/3, 1/4, 1/5} in set-builder form.

Show answer

{x : x = 1/n, n ∈ N, n ≤ 5}.

Q3. List all subsets of {a, b}.

Show answer

∅, {a}, {b}, {a, b}. That is 2² = 4 subsets.

Q4. If A = {1, 2, 3, 4, 5} and B = {4, 5, 6, 7}, find A ∪ B, A ∩ B, A − B, B − A and A Δ B.

Show answer

A ∪ B = {1, 2, 3, 4, 5, 6, 7}, A ∩ B = {4, 5}, A − B = {1, 2, 3}, B − A = {6, 7}, A Δ B = {1, 2, 3, 6, 7}.

Q5. U = {1, 2, …, 10}, A = {1, 3, 5, 7, 9} and B = {2, 3, 5, 7}. Find A′, B′ and verify (A ∪ B)′ = A′ ∩ B′.

Show answer

A′ = {2, 4, 6, 8, 10}, B′ = {1, 4, 6, 8, 9, 10}. A ∪ B = {1, 2, 3, 5, 7, 9}, so (A ∪ B)′ = {4, 6, 8, 10}. Also A′ ∩ B′ = {4, 6, 8, 10}. Verified.

Q6. How many subsets and proper subsets does a set of 5 elements have?

Show answer

2⁵ = 32 subsets and 32 − 1 = 31 proper subsets.

Q7. In a class of 40 students, 25 play hockey, 20 play cricket and 10 play both. How many play neither game?

Show answer

n(H ∪ C) = 25 + 20 − 10 = 35. So 40 − 35 = 5 students play neither.

Q8. Show that if A ∪ B = A ∩ B, then A = B.

Show answer

A ⊆ A ∪ B = A ∩ B ⊆ B, so A ⊆ B. Also B ⊆ A ∪ B = A ∩ B ⊆ A, so B ⊆ A. Hence A = B.

Revision Notes

Quick summary and common mistakes.

Quick summary

  • A set is a well-defined collection of distinct objects. It can be written in roster form or set-builder form.
  • Empty, singleton, finite, infinite, equal and equivalent sets are the basic types. {0} and {∅} are not empty.
  • A set with n elements has 2ⁿ subsets, 2ⁿ − 1 proper subsets, and its power set has 2ⁿ elements.
  • A ∪ B means "or", A ∩ B means "and", A − B means "in A not in B", and A′ means "in U not in A".
  • A Δ B = (A − B) ∪ (B − A) holds the elements that are in exactly one of the two sets.
  • De Morgan's laws: (A ∪ B)′ = A′ ∩ B′ and (A ∩ B)′ = A′ ∪ B′.
  • n(A ∪ B) = n(A) + n(B) − n(A ∩ B). For 3 sets, add the triple intersection back.
  • In JEE problems, draw a Venn diagram first, and fix the required elements before counting subsets.

Common mistakes

  • Confusing ∈ with ⊆: 1 ∈ {1, 2}, but {1} ⊆ {1, 2}.
  • Treating {0} or {∅} as the empty set. Each has one element.
  • Forgetting ∅ and the set itself when counting subsets.
  • Mixing up proper subsets (2ⁿ − 1) and non-empty proper subsets (2ⁿ − 2).
  • Writing A − B = B − A. In general they are different.
  • Finding a complement without stating the universal set.
  • Forgetting to subtract n(A ∩ B), so common elements are counted twice.
