Introduction

Meaning and importance of the topic.

A quadratic equation is an equation of degree 2: ax² + bx + c = 0, where a ≠ 0. Its solutions are called the roots (or zeros).

Its graph is a parabola. The roots are the points where the parabola cuts the x-axis, so every algebra fact about roots has a picture.

Why it matters for JEE Main

Nature and location of roots are asked directly. D = 0 gives tangency in Coordinate Geometry. Maximum and minimum values, inequalities, sequences and complex numbers all use quadratics as a tool.

Predict first. If a > 0 and D < 0, where is the parabola? Pick one, then test it in the Parabola Lab below.

Basic Concepts

Definitions and fundamental properties.

A root can be found in three ways: factorisation, completing the square, or the quadratic formula.

x = (−b ± √D) / 2a, where D = b² − 4ac
Why the formula works (proof).
Show derivation

Divide by a: x² + (b/a)x = −c/a. Add (b/2a)² to both sides: (x + b/2a)² = (b² − 4ac)/4a². Take square roots: x + b/2a = ±√D / 2a. Hence x = (−b ± √D)/2a.

What each coefficient does

a decides the opening (up if a > 0, down if a < 0) and the width. c is the y-intercept. The axis of the parabola is x = −b/2a.

Theory & Theorems

Complete explanation of the concepts that JEE tests.

Nature of roots

DiscriminantRoots (a, b, c real)
D > 0Real and distinct. Rational if D is a perfect square and a, b, c are rational. Otherwise irrational (and then they come as a conjugate pair p ± √q when a, b, c are rational).
D = 0Real and equal: x = −b/2a.
D < 0Non-real complex roots, a conjugate pair p ± iq.

Relations between roots

α + β = −b/a,   αβ = c/a
Theorem (symmetric expressions). Never solve for the roots. Write everything in S = α + β and P = αβ.
Results and proof idea

α² + β² = S² − 2P. α³ + β³ = S³ − 3PS. 1/α + 1/β = S/P. (α − β)² = S² − 4P = D/a², so |α − β| = √D / |a|.

Equation with roots α, β:   x² − (α + β)x + αβ = 0

IntermediateExample. Form the equation whose roots are the squares of the roots of x² − 5x + 3 = 0.

Show solution

S = 5, P = 3. New sum = α² + β² = 25 − 6 = 19. New product = P² = 9. Equation: x² − 19x + 9 = 0.

Sign and extreme value of ax² + bx + c

  • If D < 0: f(x) has the same sign as a for every real x.
  • If D ≥ 0 (roots α ≤ β): f(x) has the sign of a outside the roots, and the opposite sign between them.
  • Vertex at x = −b/2a, with value −D/4a. If a > 0 this is the minimum. If a < 0 it is the maximum.
JEE use

"ax² + bx + c > 0 for all x" means a > 0 and D < 0. Turn the Lab's sign colours on to see why.

Location of roots

Let f(x) = ax² + bx + c and let the roots be real. Test a number k with the "Test a point k" option in the Lab.

SituationConditions
Both roots > kD ≥ 0, −b/2a > k, a·f(k) > 0
Both roots < kD ≥ 0, −b/2a < k, a·f(k) > 0
k lies between the rootsa·f(k) < 0
Both roots in (k₁, k₂)D ≥ 0, k₁ < −b/2a < k₂, a·f(k₁) > 0, a·f(k₂) > 0
Exactly one root in (k₁, k₂)f(k₁)·f(k₂) < 0 (check the end points separately when f(k₁) or f(k₂) is 0)

Common roots

If a₁x² + b₁x + c₁ = 0 and a₂x² + b₂x + c₂ = 0 have exactly one common root, then:

(c₁a₂ − c₂a₁)² = (a₁b₂ − a₂b₁)(b₁c₂ − b₂c₁)

If both roots are common, then a₁/a₂ = b₁/b₂ = c₁/c₂.

Practice

Class 11/12 board-level questions and a JEE Main speed round.

NCERT-style questions (written in the style of the textbook, not copied from it):

Q1. Solve 2x² − 7x + 3 = 0 by factorisation.

Show answer

2x² − 6x − x + 3 = 2x(x − 3) − 1(x − 3) = (2x − 1)(x − 3). So x = 1/2 or x = 3.

Q2. Find the nature of the roots of 2x² − 4x + 3 = 0.

Show answer

D = 16 − 24 = −8 < 0, so the roots are non-real (complex conjugates).

Q3. If α, β are the roots of x² − 6x + 4 = 0, find α² + β².

Show answer

S = 6, P = 4. α² + β² = 36 − 8 = 28.

Q4. Form the quadratic equation with roots 3 + √2 and 3 − √2.

Show answer

S = 6, P = 9 − 2 = 7. The equation is x² − 6x + 7 = 0.

Q5. Find k for which x² + kx + 9 = 0 has equal roots.

Show answer

D = k² − 36 = 0, so k = 6 or k = −6.

Q6. Find the maximum value of −x² + 4x + 1.

Show answer

The vertex is at x = −b/2a = 2. Value = −4 + 8 + 1 = 5.

Revision Notes

Quick summary and common mistakes.

  • ax² + bx + c = 0 (a ≠ 0) has roots x = (−b ± √D)/2a with D = b² − 4ac.
  • D > 0 real distinct, D = 0 real equal, D < 0 complex conjugates.
  • α + β = −b/a and αβ = c/a. Write every symmetric expression in terms of these two.
  • For a > 0 the parabola has a minimum at x = −b/2a with value −D/4a. For a < 0 it has a maximum.
  • Location of roots: check D, the axis −b/2a, and the sign of a·f(k).
  • Shortcuts: a + b + c = 0 ⇒ root 1. Ratio m : n ⇒ mn·b² = (m + n)²·ac.

Trap alerts

  • Dividing both sides by x loses the root x = 0. Factorise instead.
  • "Real roots" means D ≥ 0, but "real and distinct" means D > 0.
  • In (k − 1)x² + 3x + 2 = 0, the equation is quadratic only when k ≠ 1.
  • Equations with √ or logarithms can give extra roots. Always substitute back.
  • For location of roots, one condition is not enough: check D, the axis and a·f(k) together.
  • Solving k² ≥ 16 as −4 ≤ k ≤ 4 reverses the inequality.
